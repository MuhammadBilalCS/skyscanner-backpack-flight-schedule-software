# skyscanner-backpack-flight-schedule-software
A simple React application built with [Backpack](https://backpack.github.io/) – Skyscanner’s design system. It demonstrates a flight schedule interface with a calendar for date selection.

## Features
- Backpack Calendar component with month navigation and date selection.
- Clean, accessible UI following Skyscanner’s design principles.
- Lightweight setup using `@skyscanner/backpack-react-scripts`.

## Getting Started
1. Clone the repo.
2. Run `npm install`.
3. Start the dev server with `npm start`.
4. Open [http://localhost:3000](http://localhost:3000).

## Project Structure
- `src/App.js` – main application logic and UI.
- `src/App.scss` – custom styling (optional).

## Testing
Run `npm test` to execute the default test suite.
